# Portfólio — Raphael Riquetto

Portfólio pessoal desenvolvido com HTML, CSS e JavaScript puro.

## Estrutura

- `index.html` — estrutura e conteúdo da página
- `css/style.css` — visual, layout e responsividade
- `js/script.js` — menu mobile e ano automático
- `img/` — pasta reservada para imagens

## Como executar

1. Extraia o projeto.
2. Abra a pasta no VS Code.
3. Abra o `index.html` no navegador.

Para uma experiência melhor no desenvolvimento, pode usar a extensão **Live Server** do VS Code.
